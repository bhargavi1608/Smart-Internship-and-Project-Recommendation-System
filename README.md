# Smart-Internship-and-Project-Recommendation-System

## 📌 Overview

The **Smart Internship & Project Recommendation System** is a web-based platform designed to help students discover suitable internships and project opportunities based on their skills, interests, and academic background. The system simplifies the process of finding relevant opportunities and enables administrators to manage internships efficiently.

This platform bridges the gap between students and opportunities by providing personalized recommendations and an easy-to-use dashboard.

---

## 🎯 Features

* **User Registration & Authentication**

  * Secure login and signup for students and administrators.

* **Internship Recommendation**

  * Suggests internships based on student skills and interests.

* **Project Recommendation**

  * Recommends relevant academic or industry projects.

* **Application Management**

  * Students can apply for internships directly through the platform.

* **Admin Dashboard**

  * Admin can manage internships, projects, and applications.

* **Email Verification**

  * User account verification through email.

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/bhargavi1608/Smart-Internship-and-Project-Recommendation-System.git
```

### 2️⃣ Backend Setup

```bash
cd backend
mvn spring-boot:run
```

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

## 📊 System Workflow

1. User registers and verifies email.
2. Student logs into the platform.
3. System analyzes student skills and preferences.
4. Recommended internships and projects are displayed.
5. Students can apply directly through the platform.
6. Admin reviews and manages applications.
